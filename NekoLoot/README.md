<h1 align="center">NekoLoot</h1>

<p align="center"><b>三平台本地敏感信息搜集工具</b></p>

<p align="center">Rust</p>

---

## 架构

```
┌──────────────┐   上传+执行通道   ┌──────────────┐
│   NekoC2     │────────────────►│   NekoLoot   │
│  (Operator)  │                 └──────┬───────┘
└──────────────┘                        │
                              ┌─────────▼─────────┐
                              │   本地信息采集模块  │
                              │ browser/credential│
                              │ chat/filescan/... │
                              └─────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │  汇总打包输出      │
                              │ (report + 采集物) │
                              └───────────────────┘
```

| 组件 | 职责 |
|------|------|
| **采集入口** | 单二进制按平台自适应加载对应采集逻辑，可指定模块子集 |
| **采集模块库** | 浏览器数据 / 系统凭据 / IM 聊天 / 敏感文件 / 软件凭据 / 网络域信息 / 用户痕迹 |
| **汇总输出** | 采集结果统一打包，输出汇总报告与分类目录 |

## 功能

- **三平台覆盖**：一套源码产出 Windows / macOS / Linux 独立二进制，自动使用各平台采集逻辑
- **浏览器数据**：主流浏览器整库采集（历史 / Cookie / 登录数据 / 书签），凭据现场解密
- **系统凭据**：凭据管理器、WiFi 密码、RDP 配置、DPAPI 主密钥、内存凭据转储
- **IM 聊天记录**：微信 / QQ / 钉钉 / 飞书 / 企业微信 数据目录整包采集，进程内提取解密密钥
- **敏感文件扫描**：按敏感路径 / 后缀 / 内容关键词命中并复制
- **软件凭据与令牌**：常见运维 / 开发软件凭据、容器配置、云 CLI 令牌
- **网络与域信息**：网络配置、域用户 / 管理员组、SPN、DNS 缓存
- **用户痕迹**：Shell 历史、剪贴板历史、最近文档、邮件客户端数据、Telegram / Discord 数据
- **模块化调用**：可按需指定模块子集，避免无谓痕迹
- **C2 联动**：由 NekoC2 走上传 + 执行通道调用，结果回传统一归档
