<h1 align="center">NekoPriv</h1>

<p align="center"><b>Linux 本地安全测试终端工具</b></p>

<p align="center">Go</p>

---

## 架构

```
┌──────────────┐   命令行执行     ┌──────────────┐
│   Operator   │────────────────►│  NekoPriv    │
└──────────────┘                 └──────┬───────┘
                                        │
                              ┌─────────▼─────────┐
                              │   目标环境探测      │
                              │ (内核/发行版/配置)  │
                              └─────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │   提权模块执行      │
                              │  (按 CVE 编号调用)  │
                              └───────────────────┘
```

| 组件 | 职责 |
|------|------|
| **终端入口** | 命令行交互，按 CVE 编号 / 别名 / 参数指定目标模块 |
| **环境探测** | 自动识别目标系统内核版本、发行版、sudo 配置、已装软件包，辅助判断可用模块 |
| **提权模块库** | 内置多个 Linux 本地提权模块，支持按 CVE 名称或别名一键执行 |

## 功能

- **本地权限提升**：面向授权靶机 / 虚拟机 / 实验环境的 Linux 本地提权，多内核模块按需调用
- **按 CVE 执行**：指定 CVE 编号或别名直接运行对应模块，无需手工构造利用步骤
- **环境自适应**：自动探测内核 / 发行版 / 关键配置，跨主流发行版运行
- **国产信创实测**：openEuler / 统信 UOS / openKylin / AnolisOS 等信创系统实测通过
- **单二进制**：Go 静态编译，单文件部署，无运行时依赖
- **结果可复现**：模块执行结果与目标环境明确记录，便于授权测试报告归档
