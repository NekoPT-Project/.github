## 架构

```
┌─────────────────────┐          ┌──────────────────────────┐
│   vshell Agent      │          │   C2 服务器（单进程）      │
│  （原生，零改动）     │          │   Web 管理面板             │
└─────────┬───────────┘          │   REALITY 伪装入口         │
          │                      │   vshell 对接             │
┌─────────▼───────────┐          └────────────┬─────────────┘
│   NekoVWrap         │                       │
│   目标侧转发代理     │════ 伪装出站流量 ═════▶│
└─────────────────────┘                       ▼
                                        vshell 原生监听
```

| 组件 | 职责 |
|------|------|
| **目标侧代理** | 监听本机回联端口，把 agent 的出站通信逐连接包进伪装外壳；服务上下文部署兼容 |
| **服务器侧入口** | 与 vshell 同机部署，接收伪装流量并转发给 vshell 原生监听，探测流量被引导至真实网站 |
| **Web 管理面板** | 入口组管理、监听器自动创建与生命周期同步、多平台产物一键构建与下载 |

## 功能

- **流量伪装**：agent 出站通信被包装成对真实网站的普通加密访问，被动流量分析无法识别出 C2 通信特征
- **防主动探测**：对入口端口的探测请求被引导到真实网站，返回真实站点内容，无法判定为 C2 服务
- **原生 agent 零改动**：不修改 agent 任何字节，透明转发；agent 由 vshell 原生生成，与官方行为完全一致
- **两文件拆分部署**：代理与 agent 独立文件，同机部署或代理置于跳板机做网关均可
- **Web 面板一键管理**：入口组启停/删除与监听器全生命周期同步，配置保存即热更新
- **多平台产物**：Windows / Linux 双系统、64/32 位全架构一键构建
- **自动重连**：隧道链路中断自动重建，agent 无需干预即可恢复上线
