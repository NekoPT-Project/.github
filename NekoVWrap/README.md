<p align="center"><b>vshell 专用流量包装器</b></p>

## 架构

```
┌──────────────┐    Web 管理     ┌──────────────┐
│   vshell     │◄───────────────►│   C2 服务器   │
│   Web 控制台  │   (8078/8082)  │   vshell     │
└──────────────┘                └──────┬───────┘
                                       │
                              ┌────────▼────────┐
                              │    NekoVWrap    │
                              │  服务器侧入口    │
                              └────────┬────────┘
                                       │ 伪装出站流量
                              ┌────────▼────────┐
                              │  NekoVWrap      │
                              │  目标侧单文件    │
                              └─────────────────┘
                                       │
                                       ▼
                                  vshell Agent
```

| 组件 | 职责 |
|------|------|
| **目标侧单文件** | 随 vshell agent 一起投递，单进程静默后台运行，把 agent 的出站通信包进伪装外壳 |
| **服务器侧入口** | 与 vshell 同机部署，接收伪装流量并转发给 vshell 原生监听，对外只暴露一个标准端口 |
| **一键构建工具** | 一条命令完成：密钥生成、监听器配置、payload 打包，产出可投递的单文件 |

## 功能

- **流量伪装**：agent 出站通信被包装成对真实网站的普通加密访问，被动流量分析无法识别出 C2 通信特征
- **防主动探测**：对 C2 暴露端口的探测请求被引导到真实网站，返回真实站点内容，无法判定为 C2 服务
- **单文件投递**：目标侧仅一个可执行文件，随 agent 落地即可，无需安装运行时或额外组件
- **静默后台**：Windows 下无窗口、无控制台常驻，进程消失即 agent 失联
- **自动重连**：隧道链路中断自动重建，agent 无需干预即可恢复上线
- **零目标环境依赖**：通信全部在进程内完成，不依赖目标机任何服务或配置
- **一键构建**：服务器侧 `build` 一条命令产出全部产物（密钥、服务端入口、目标侧单文件），并自动校验配置一致性
