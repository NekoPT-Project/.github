## 特点

- **全流程自研**：目标覆盖渗透测试各阶段所需能力，不依赖「拼凑开源工具链」
- **自研协议与实现**：通信与核心逻辑自主设计，规避常见开源工具的已知特征与签名
- **模块化组合**：各工具可独立使用，也可按任务灵活串联
- **持续扩充**：围绕实战缺口补齐组件，公开介绍会随新工具同步更新
